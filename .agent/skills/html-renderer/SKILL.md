# HTML Renderer — FrameForge Extension

Renders video frames as HTML pages (one page = one frame clock) using
Playwright for screenshot capture and FFmpeg for final encoding.

Built on deterministic `seek(t)` — every style is a pure function of time `t`.
No CSS transitions, no `setTimeout`, no frame state that depends on the
previous frame (Playwright renders frames out of order for parallelism).

---

## When to use this renderer

| Use FFmpeg zoompan (default)       | Use HTML renderer (this skill)       |
|------------------------------------|--------------------------------------|
| Batch overnight — speed matters    | Animation quality is the priority    |
| Simple Ken-Burns + captions        | Kinetic text, counters, data charts  |
| CI/server with no browser          | Morphing layouts, spring physics     |
| < 5 min render time required       | Creator wants Remotion-style output  |
| Raspberry Pi / low-RAM machine     | macOS/Linux with 4GB+ free RAM       |

---

## Requirements

- Node.js 18+, FFmpeg, `npx playwright install chromium`
- macOS or Linux recommended (Windows: WSL2)
- 4 GB+ free RAM (Playwright renders up to 6 subframes per output frame in
  parallel for motion blur)
- `uv` (Python) for audio processing scripts: `pip install uv` or
  `curl -LsSf https://astral.sh/uv/install.sh | sh`

## Setup

```bash
# Install Playwright chromium (one-time)
npx playwright install chromium

# Scaffold a new HTML-renderer project from a FrameForge script JSON
node <frameforge-root>/scripts/html-renderer/new-project.mjs \
  --script output/<productionId>-script.json \
  --out    output/<productionId>-html/
```

The scaffold copies `index.html` (compositor), starter `edit.js`, the
`reel/engine.js` runtime, and all render scripts into the project folder.

## Core concept: `seek(t)`

```js
// edit.js — every element style is computed from t (seconds)
import { reel, faceAt, layer, text, at, captions } from './reel/engine.js';

reel({ width: 1920, height: 1080, fps: 30, duration: 65 });

// Title card: fades in at t=0, stays for 3s
layer('hook').on(t => ({
  opacity: t < 0.3 ? t / 0.3 : t > 2.7 ? (3 - t) / 0.3 : 1,
}));

at(0, text('Why Ancient Humans Started Cooking', {
  font: '72px/1.2 "Archivo"', color: '#fff',
  x: 'center', y: 200,
}));

// Caption synced to FrameForge TTS audio
captions('audio/outline.txt');  // generated by transcribe.py
```

**Iron rule:** Every style must be a pure function of `t`. If a layer is
active during frames 5–15 s and you `return` early for t > 15, it must
explicitly reset every property it drove — otherwise the last frame's value
sticks on all later frames.

## Workflow (integrates with FrameForge pipeline)

### Step 1: Run FrameForge dry-run to get script JSON

```bash
npm run make -- --topic "Your Topic" --dry-run --out-dir output/my-topic
# Produces: output/my-topic/<productionId>-script.json
```

### Step 2: Scaffold the HTML compositor project

```bash
node scripts/html-renderer/new-project.mjs \
  --script output/my-topic/<productionId>-script.json \
  --out    output/my-topic/html-render/
```

The scaffolder reads each scene's `narration`, `caption`,
`visual_description`, `camera_hint`, and `music_mood` from the script JSON
and generates a starter `edit.js` with one `layer()` per scene, timed to
the expected narration duration (estimated at 2.5 words/second).

### Step 3: Gather assets (optional)

```bash
# Stock footage
uv run scripts/stock.py video "ancient cooking fire" --portrait

# Website screenshot as b-roll
node scripts/capture.mjs site https://example.com broll-site

# X post card
node scripts/capture.mjs tweet https://x.com/... post-card
```

### Step 4: Check visually before full render

```bash
# Contact sheet — one frame every 0.5s
node scripts/render.mjs sheet

# Specific timestamps
node scripts/render.mjs stills 0 5.5 12 28 45 60
```

### Step 5: Mix audio

```bash
uv run scripts/mix_audio.py
# Reads FrameForge TTS outputs, applies -14 LUFS, writes out/audio_mix.m4a
```

### Step 6: Full render + verify

```bash
node scripts/render.mjs full
uv run scripts/verify.py
```

Output: `out/<name>.mp4` (1920x1080 or 1080x1920 for Shorts), verified
against the same FrameForge quality gates (resolution, codec, LUFS, A/V sync).

### Step 7: Re-inject into FrameForge pipeline

The rendered MP4 can be injected back into FrameForge via `video_path`:

```json
{
  "scene_id": 1,
  "video_path": "output/my-topic/html-render/out/video.mp4"
}
```

Or pass it directly to `publish_video` via MCP:

```
publish_video(productionId, masterPath="output/my-topic/html-render/out/video.mp4", channels=["file","webhook"])
```

## Engine API quick reference

| Function | What it does |
|---|---|
| `reel({ width, height, fps, duration })` | Configure the compositor |
| `layer('name').on(t => styles)` | Declare a layer; styles recomputed every frame |
| `at(t, element)` | Place element at time t |
| `stagger(t, dt, elements[])` | Place elements with dt spacing |
| `text(str, opts)` | Animated text with font/color/position |
| `chip(str, opts)` | Pill-shaped label (tags, captions) |
| `wallCard(lines[], opts)` | Frosted-glass card over background |
| `imageCard(src, opts)` | Image with optional caption overlay |
| `browserCard(url, opts)` | Screenshot-as-card |
| `terminal(lines[], opts)` | Animated terminal output |
| `stamp(str, opts)` | Bold diagonal stamp (VERIFIED, SOURCE, etc.) |
| `codeCard(code, lang, opts)` | Syntax-highlighted code block |
| `captions(outlinePath)` | Auto-sync captions from whisper outline |
| `cuePhrase(phrase, offset)` | Word-level trigger with fail-fast transcript check |
| `cue(sfxName, t, vol)` | Trigger sound effect at time t |
| `event(type, t, meta)` | Declare a composition event for render.mjs to consume via `window.__events()` |
| `faceAt(layout, t)` | Position talking-head face (FULL, SPLIT, PIP) |
| `hash(i)` | Deterministic PRNG float [0, 1) for index i |
| `boilSeed(key, t)` | Deterministic stepped float [0, 1) in 1/12s window |
| `kf(t, keys, ease)` | Keyframe interpolation with easing curves |
| `onTwos(t)` | Quantize time to 12 fps (traditional animation on twos) |
| `seg(t, a, b)` | Clamp t into [0, 1] interval progress |
| `pulse(t, k)` | Exponential impulse peak at t=0, decaying with rate k |
| `shots(timeline)` | Time-ordered shot registry fn(t, lt, dur) for parallel render |
| `on(t => ...)` | Raw per-frame compute (for custom animations) |
| `beatAt(index, bpm, fps)` | Beat frame index (HyperFrames formula — round per-index, never accumulated) |
| `beatTime(index, bpm)` | Beat timestamp in seconds |
| `snapToBeat(t, bpm)` | Snap a timestamp to the nearest beat boundary |
| `OM.spring(t, opts)` | OneTake spring entrance → `{ transform, opacity }` |
| `OM.iris(t, opts)` | Radial clip expand from centre → `{ clipPath }` |
| `OM.morphRect(t, opts)` | Clip from narrow rect to full frame → `{ clipPath }` |
| `OM.zoomThrough(t, opts)` | Portal scale-through → `{ transform }` |
| `OM.camera(t, opts)` | Ken Burns + seeded micro-shake → `{ transform }` |
| `OM.carryScore(t)` | Carry momentum at exit (must be ≥ 0.5 to PASS oracle) |
| `ROOM_SFX` | OneTake 5-material SFX palette (air/wood/glass/sub/bubble) for `cue()` |

## Storyboard Gates, Purity Verification & Review Modes

```bash
# 1. Diagnostic & Setup checks
node scripts/harness.mjs doctor        # Verify Chrome, GPU flags (D3D11/Metal), WebGL context
node scripts/look.mjs                  # Pre-render linter (fonts, clipping, NaN transforms)

# 2. Purity verification gate (3-point repeat, wander, cold-jump test)
node scripts/harness.mjs verify        # Must pass a===b and a===c across 9 sampled timestamps

# 3. Gate stills & review commands
node scripts/harness.mjs storyboard    # 4 keyframes (0%, 33%, 66%, 100%) or validate STORYBOARD.md
node scripts/harness.mjs sheet         # Contact sheet (0.5s interval)
node scripts/harness.mjs strip 1.0 1.5 # Horizontal frame strip (motion check)
node scripts/harness.mjs crop 9:16     # Focal-point mobile crop preview
node scripts/harness.mjs pixels        # Blind-spot frame analysis (blank, blown, corner-confined)

# 4. Master render & encode
node scripts/harness.mjs frames        # Resumable atomic frame render (.tmp + renameSync)
node scripts/harness.mjs encode        # BT.709 color-tagged master encode + audio mux
node scripts/harness.mjs all           # Complete gate-checked end-to-end production
node scripts/render.mjs mux            # Re-mux audio only (no re-render)
node scripts/render.mjs kit            # Editor kit (Premiere/Resolve XML)
```

Full render uses 6-page parallel Playwright pool (motion blur subframes).
Long videos render in 60s resumable chunks — re-run to continue after crash.

## Gotchas

- **Pure functions of t.** No CSS transitions, `setTimeout`, or state that
  depends on previous frames. Playwright seeks out of order.
- **Every style must reset.** If a layer returns early after t > 15s, it
  must explicitly set opacity/display/visibility to 0/none/hidden — or the
  last rendered value bleeds onto all later frames.
- **HDR iPhone footage** needs tonemapping before compositing
  (`uv run scripts/assemble.py` does this automatically).
- **Motion blur needs 6 subframes.** Fewer subframes show fast morphs as
  ghost copies. Default is 6 (180° shutter), a 60s video takes ~4 min.
- **Measure text after fonts load.** Components that need widths (strike-
  through, underline) measure lazily on first `seek()`.
- **Captions over the mouth.** Use `REEL.captionY` per layout to move them
  to the seam in split-screen mode.
